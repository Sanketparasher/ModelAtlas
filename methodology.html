The Elo Inflation Time Machine

Why don't we rank GPT-4-0314 as the #1 model in the world? Toggle the live time-machine below to see how Bradley-Terry matchmaking drift distorts raw numbers without ModelAtlas calibration.

🕰️
The Problem: When GPT-4 launched in March 2023, it battled weak models like GPT-3.5 and Llama 1, earning a massive historical Elo of 1443. Modern champions like Claude 3.7 Sonnet (1362) only fight super-intelligent opponents. Raw rankings create a broken trust signal by ranking ancient 2023 models above modern frontier AI.
🔬 For Math & Research Nerds: The Normalization Formula ▾
$$\text{isObsoleteLegacy}(m) := \text{RegexMatch}(m, [\text{GPT-4-0314}, \text{Claude-1}, \text{Qwen1.5}, \text{Llama-2}, \dots])$$ $$\text{EffectiveElo}(m) := \text{RawElo}(m) - (\text{isObsoleteLegacy}(m) \;?\; 250 : 0)$$
A -250 Elo correction penalty calibrates the 2023 baseline against contemporary frontier matchmaking distributions without deleting historical models from research archives.

Hardware Physics 05

Local VRAM Sizing & KV Cache Memory Physics

Move the Context Length Slider below to watch how the Key-Value (KV) Cache dynamically inflates the total VRAM consumption across different machine classes.

🖥️
The Trap: Many developers believe a "70B model only needs 40GB VRAM." That is true only for short inputs! When you feed a 70B model a 128,000-token context, the Key-Value (KV) cache alone consumes an extra 16GB to 32GB of GPU memory. ModelAtlas models both weights and KV cache to prevent out-of-memory errors.

🔬 Mathematical Equations: Memory Footprint & KV Cache ▾
$$\text{VRAM}_{\text{Weights}} \approx \text{Parameters (B)} \times 0.55\text{ GB} + 1.2\text{ GB (CUDA Overhead)}$$ $$\text{KV Cache Memory (Bytes)} = 2 \times n_{\text{layers}} \times n_{\text{heads}} \times d_{\text{head}} \times \text{Tokens} \times \text{BytesPerElement}$$
For FP16 KV cache, BytesPerElement = 2. When running 128k context, FP8 quantization (BytesPerElement = 1) or PagedAttention is mathematically required to avoid out-of-memory kernel panics.
